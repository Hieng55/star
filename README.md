# Màn Sao Chuyển Động

Trang tĩnh toàn màn hình mô phỏng bầu trời sao chuyển động bằng Canvas.

## Mở nhanh trên Windows

Nhấp đúp vào `MỞ-MÀN-SAO.bat`. Tệp này sẽ bật máy chủ cục bộ và tự mở đúng địa chỉ trong trình duyệt.

## Xem tại máy

Mở một máy chủ tĩnh tại thư mục dự án, ví dụ:

```powershell
python -m http.server 4173
```

Sau đó mở `http://localhost:4173`. Trang gốc sẽ tự chuyển vào `dist/`.
